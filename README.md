# AI 工作流模板库

把小红书作品中的方法整理成可直接复制的 Prompt 和可下载的 Skill。

## 在线访问

- GitHub Pages: <https://404-notfound-coder.github.io/>
- Sites: <https://peter-ai-workflows.jma83170.chatgpt.site/>

## 本地运行

```bash
npm install
npm run dev
```

## 验证与导出

```bash
npm test
npm run export:pages
```

推送到 `main` 后，GitHub Actions 会自动构建并更新 GitHub Pages。
