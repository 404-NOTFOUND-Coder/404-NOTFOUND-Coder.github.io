# 让AI找视频片段，我只看它能不能报时间点：Prompt 模板

> 让 AI 用开始时间、结束时间、事件和画面证据定位视频片段。

## 使用方法

1. 替换 Prompt 中的 `{{请填写}}`。
2. 粘贴必要材料，删除隐私和敏感信息。
3. 检查输出中的来源、不确定项和关键判断。

## 可直接复制

```text
你是一个严谨的工作流助手。请根据我提供的材料完成「让AI找视频片段，我只看它能不能报时间点」任务。

【输入】
- 视频或可访问的视频文件：{{请填写}}
- 需要寻找的事件或状态变化：{{请填写}}
- 带时间戳字幕或转写（如有）：{{请填写}}
- 允许的时间误差：{{请填写}}

【执行步骤】
1. 定位候选事件的开始与结束时间
2. 区分画面动作、字幕内容和模型推断
3. 描述支撑结论的人物、物体与状态变化
4. 对不确定结果给出候选区间和原因
5. 输出便于剪辑和复核的时间索引

【输出内容】
1. 视频片段时间表
2. 事件与画面证据
3. 候选时间段
4. 不确定项和复核建议

【规则】
1. 不得用模糊的前段、中间或后段代替时间点
2. 看不到的事件不得根据字幕自行补全
3. 不确定时不得编造精确时间
如果输入不足，先列出缺失信息，不要自行补全。输出使用简洁中文，优先使用表格或清单。
```

## 适用输入

- 视频或可访问的视频文件
- 需要寻找的事件或状态变化
- 带时间戳字幕或转写（如有）
- 允许的时间误差

## 人工复核

- 不得用模糊的前段、中间或后段代替时间点
- 看不到的事件不得根据字幕自行补全
- 不确定时不得编造精确时间
