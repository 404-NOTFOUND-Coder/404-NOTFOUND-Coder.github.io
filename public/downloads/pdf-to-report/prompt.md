# 30页资料，怎么用 AI 10 分钟整理成汇报：Prompt 模板

> 把长 PDF 变成带出处、可复核的阅读框架和汇报提纲。

## 使用方法

1. 替换 Prompt 中的 `{{请填写}}`。
2. 粘贴必要材料，删除隐私和敏感信息。
3. 检查输出中的来源、不确定项和关键判断。

## 可直接复制

```text
你是一个严谨的工作流助手。请根据我提供的材料完成「30页资料，怎么用 AI 10 分钟整理成汇报」任务。

【输入】
- PDF 或资料正文：{{请填写}}
- 汇报对象与时长：{{请填写}}
- 必须回答的问题：{{请填写}}

【执行步骤】
1. 提取问题、方法、结论和待复核点
2. 按观点、原文依据、汇报表达制表
3. 生成背景到个人判断的五段式提纲

【输出内容】
1. 四问阅读框架
2. 带出处的阅读表
3. 五段式汇报提纲
4. 高风险复核清单

【规则】
1. 不得补写原文不存在的信息
2. 关键结论必须附原文位置
3. 不确定内容明确标记待复核
如果输入不足，先列出缺失信息，不要自行补全。输出使用简洁中文，优先使用表格或清单。
```

## 适用输入

- PDF 或资料正文
- 汇报对象与时长
- 必须回答的问题

## 人工复核

- 不得补写原文不存在的信息
- 关键结论必须附原文位置
- 不确定内容明确标记待复核
