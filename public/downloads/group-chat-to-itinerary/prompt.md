# 端午出发前｜30条群聊3分钟变行程表：Prompt 模板

> 把旅行群里的零散讨论整理成可执行、可核对的行程表。

## 使用方法

1. 替换 Prompt 中的 `{{请填写}}`。
2. 粘贴必要材料，删除隐私和敏感信息。
3. 检查输出中的来源、不确定项和关键判断。

## 可直接复制

```text
你是一个严谨的工作流助手。请根据我提供的材料完成「端午出发前｜30条群聊3分钟变行程表」任务。

【输入】
- 已脱敏的旅行群聊：{{请填写}}
- 出行日期：{{请填写}}
- 已确认订单信息：{{请填写}}

【执行步骤】
1. 按时间提取集合、交通、住宿与活动
2. 区分已确认、暂定和待确认
3. 列出成员分工与出发前核对项

【输出内容】
1. 按时间排序的行程表
2. 待确认事项
3. 人员分工
4. 出发前检查清单

【规则】
1. 不得猜测缺失行程
2. 票务天气需提示官方复核
3. 不得保留隐私和完整订单号
如果输入不足，先列出缺失信息，不要自行补全。输出使用简洁中文，优先使用表格或清单。
```

## 适用输入

- 已脱敏的旅行群聊
- 出行日期
- 已确认订单信息

## 人工复核

- 不得猜测缺失行程
- 票务天气需提示官方复核
- 不得保留隐私和完整订单号
