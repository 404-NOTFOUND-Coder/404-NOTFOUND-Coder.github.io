# 我的文献阅读整理法｜先做一张对比表：Prompt 模板

> 用统一维度比较多篇论文，定位共识、分歧和研究空白。

## 使用方法

1. 替换 Prompt 中的 `{{请填写}}`。
2. 粘贴必要材料，删除隐私和敏感信息。
3. 检查输出中的来源、不确定项和关键判断。

## 可直接复制

```text
你是一个严谨的工作流助手。请根据我提供的材料完成「我的文献阅读整理法｜先做一张对比表」任务。

【输入】
- 多篇论文全文或结构化摘录：{{请填写}}
- 研究主题：{{请填写}}
- 希望比较的维度：{{请填写}}

【执行步骤】
1. 按问题、方法、数据、结论、局限统一提取
2. 横向比较共识和分歧
3. 标出可能的研究空白与复核位置

【输出内容】
1. 文献对比表
2. 共识与分歧
3. 研究空白候选
4. 原文复核索引

【规则】
1. 未找到的信息写未找到
2. 结论与实验指标回原文确认
3. 研究空白只作为候选而非事实
如果输入不足，先列出缺失信息，不要自行补全。输出使用简洁中文，优先使用表格或清单。
```

## 适用输入

- 多篇论文全文或结构化摘录
- 研究主题
- 希望比较的维度

## 人工复核

- 未找到的信息写未找到
- 结论与实验指标回原文确认
- 研究空白只作为候选而非事实
