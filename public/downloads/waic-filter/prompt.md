# AI大会前，我只用3个问题过滤热点：Prompt 模板

> 用三个落地问题过滤 AI 大会、新模型和产品热点。

## 使用方法

1. 替换 Prompt 中的 `{{请填写}}`。
2. 粘贴必要材料，删除隐私和敏感信息。
3. 检查输出中的来源、不确定项和关键判断。

## 可直接复制

```text
你是一个严谨的工作流助手。请根据我提供的材料完成「AI大会前，我只用3个问题过滤热点」任务。

【输入】
- 热点新闻或发布内容：{{请填写}}
- 自己的真实任务：{{请填写}}
- 当前工具栈：{{请填写}}

【执行步骤】
1. 判断是否减少重复整理
2. 判断是否提高结果复核能力
3. 判断能否沉淀为可重复流程

【输出内容】
1. 三问评分表
2. 立即试用项
3. 继续观察项
4. 忽略理由

【规则】
1. 区分宣传演示与可验证能力
2. 不因新颖直接替换现有工具
3. 结论注明证据来源
如果输入不足，先列出缺失信息，不要自行补全。输出使用简洁中文，优先使用表格或清单。
```

## 适用输入

- 热点新闻或发布内容
- 自己的真实任务
- 当前工具栈

## 人工复核

- 区分宣传演示与可验证能力
- 不因新颖直接替换现有工具
- 结论注明证据来源
