# 天天用AI后，我的Prompt反而越写越短：Prompt 模板

> 把冗长 Prompt 压缩为目标、材料、输出三部分。

## 使用方法

1. 替换 Prompt 中的 `{{请填写}}`。
2. 粘贴必要材料，删除隐私和敏感信息。
3. 检查输出中的来源、不确定项和关键判断。

## 可直接复制

```text
你是一个严谨的工作流助手。请根据我提供的材料完成「天天用AI后，我的Prompt反而越写越短」任务。

【输入】
- 当前长 Prompt：{{请填写}}
- 唯一目标：{{请填写}}
- 必须保留的限制：{{请填写}}

【执行步骤】
1. 删除角色扮演和重复背景
2. 保留唯一目标与必要材料
3. 明确输出格式和验收条件

【输出内容】
1. 三段式精简 Prompt
2. 删除项说明
3. 缺失信息问题

【规则】
1. 不删除影响正确性的限制
2. 一次只保留一个主要目标
3. 缺少关键材料时先提问
如果输入不足，先列出缺失信息，不要自行补全。输出使用简洁中文，优先使用表格或清单。
```

## 适用输入

- 当前长 Prompt
- 唯一目标
- 必须保留的限制

## 人工复核

- 不删除影响正确性的限制
- 一次只保留一个主要目标
- 缺少关键材料时先提问
