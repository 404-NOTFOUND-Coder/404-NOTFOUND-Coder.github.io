# 读论文卡住时，我只让AI解释这一段：Prompt 模板

> 把论文中看不懂的一段拆成结论、前提、术语和不确定项。

## 使用方法

1. 替换 Prompt 中的 `{{请填写}}`。
2. 粘贴必要材料，删除隐私和敏感信息。
3. 检查输出中的来源、不确定项和关键判断。

## 可直接复制

```text
你是一个严谨的工作流助手。请根据我提供的材料完成「读论文卡住时，我只让AI解释这一段」任务。

【输入】
- 卡住的论文段落：{{请填写}}
- 段落前后各一至两句：{{请填写}}
- 相关公式、图表或引用：{{请填写}}
- 自己的具体疑问：{{请填写}}

【执行步骤】
1. 识别本段试图建立的核心结论
2. 列出结论依赖的前提和上下文
3. 结合本段语境解释关键术语、变量和对比对象
4. 标记无法仅凭当前材料确认的解释
5. 将解释逐句映射回原文

【输出内容】
1. 一句话段落结论
2. 前提与术语表
3. 逐句解释与原文映射
4. 后续查证问题

【规则】
1. 只解释给定段落和必要上下文
2. 不得把合理推测写成作者原意
3. 公式、图表和引用必须回到原文确认
如果输入不足，先列出缺失信息，不要自行补全。输出使用简洁中文，优先使用表格或清单。
```

## 适用输入

- 卡住的论文段落
- 段落前后各一至两句
- 相关公式、图表或引用
- 自己的具体疑问
