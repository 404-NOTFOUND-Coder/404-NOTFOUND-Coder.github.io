# 别人问我进展时，我用3句话讲清楚：Prompt 模板

> 用完成了什么、卡在哪里、下一步做什么讲清进展。

## 使用方法

1. 替换 Prompt 中的 `{{请填写}}`。
2. 粘贴必要材料，删除隐私和敏感信息。
3. 检查输出中的来源、不确定项和关键判断。

## 可直接复制

```text
你是一个严谨的工作流助手。请根据我提供的材料完成「别人问我进展时，我用3句话讲清楚」任务。

【输入】
- 本阶段完成事项：{{请填写}}
- 当前卡点：{{请填写}}
- 下一步计划：{{请填写}}
- 时间范围：{{请填写}}

【执行步骤】
1. 从活动中筛出可验证结果
2. 用事实描述卡点与影响
3. 给出下一步动作和预计时间

【输出内容】
1. 三句话进展
2. 详细备查版
3. 需要协助项

【规则】
1. 不把忙碌当进展
2. 不隐去影响交付的卡点
3. 时间估计需说明不确定性
如果输入不足，先列出缺失信息，不要自行补全。输出使用简洁中文，优先使用表格或清单。
```

## 适用输入

- 本阶段完成事项
- 当前卡点
- 下一步计划
- 时间范围

## 人工复核

- 不把忙碌当进展
- 不隐去影响交付的卡点
- 时间估计需说明不确定性
