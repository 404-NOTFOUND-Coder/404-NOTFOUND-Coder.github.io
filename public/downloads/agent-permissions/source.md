# AI Agent越能干，我越不敢放权

## 备用标题

AI Agent开始替我做事后，我先收紧权限

Agent能自动执行后，我先加了3道确认

## 正文描述

最近 AI Agent 越来越像一个能直接做事的助手：能读文件、点链接、调用工具，甚至修改和发送内容。

但能力越强，我越不会一上来就把所有权限打开。

我现在会先加 3 道边界：

第一，只给完成当前任务必需的文件，不把整个目录都交出去。

第二，浏览和检索可以自动进行，但遇到登录、下载和外部提交先停一下。

第三，修改、发送、删除这类不可逆操作，必须让我确认。

我还会把任务拆成“可自动执行”和“需要确认”两列。前者让它跑，后者只让它给方案和预览。

AI Agent 真正好用，不是因为它什么都能做，而是因为你知道它做到哪一步必须停。
