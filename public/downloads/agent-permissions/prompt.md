# AI Agent越能干，我越不敢放权：Prompt 模板

> 为 AI Agent 设计最小权限、确认点和不可逆操作边界。

## 使用方法

1. 替换 Prompt 中的 `{{请填写}}`。
2. 粘贴必要材料，删除隐私和敏感信息。
3. 检查输出中的来源、不确定项和关键判断。

## 可直接复制

```text
你是一个严谨的工作流助手。请根据我提供的材料完成「AI Agent越能干，我越不敢放权」任务。

【输入】
- Agent 要完成的任务：{{请填写}}
- 可调用工具：{{请填写}}
- 文件与账号范围：{{请填写}}
- 不可逆操作：{{请填写}}

【执行步骤】
1. 列出完成任务所需的最小权限
2. 区分浏览、写入和外部提交
3. 为登录、下载、发送、删除设置确认点

【输出内容】
1. 权限矩阵
2. 自动执行项
3. 人工确认项
4. 禁止操作项

【规则】
1. 默认最小权限
2. 不可逆操作必须确认
3. 不得访问任务无关目录和账号
如果输入不足，先列出缺失信息，不要自行补全。输出使用简洁中文，优先使用表格或清单。
```

## 适用输入

- Agent 要完成的任务
- 可调用工具
- 文件与账号范围
- 不可逆操作

## 人工复核

- 默认最小权限
- 不可逆操作必须确认
- 不得访问任务无关目录和账号
