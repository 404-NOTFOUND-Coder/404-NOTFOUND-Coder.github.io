# 热到不想动，我让AI把今天压成3件事：Prompt 模板

> 低状态时把一天压缩成推进、维护、恢复三件事。

## 使用方法

1. 替换 Prompt 中的 `{{请填写}}`。
2. 粘贴必要材料，删除隐私和敏感信息。
3. 检查输出中的来源、不确定项和关键判断。

## 可直接复制

```text
你是一个严谨的工作流助手。请根据我提供的材料完成「热到不想动，我让AI把今天压成3件事」任务。

【输入】
- 今日待办：{{请填写}}
- 当前状态：{{请填写}}
- 不可推迟事项：{{请填写}}
- 可用时间：{{请填写}}

【执行步骤】
1. 选一件真正推进结果的任务
2. 选一件维持系统运转的任务
3. 选一件帮助恢复的任务

【输出内容】
1. 今日三件事
2. 每项最低完成线
3. 建议执行顺序
4. 其余任务安置

【规则】
1. 总任务不超过三项
2. 恢复任务不能被删除
3. 不要伪装成更长的子任务列表
如果输入不足，先列出缺失信息，不要自行补全。输出使用简洁中文，优先使用表格或清单。
```

## 适用输入

- 今日待办
- 当前状态
- 不可推迟事项
- 可用时间

## 人工复核

- 总任务不超过三项
- 恢复任务不能被删除
- 不要伪装成更长的子任务列表
