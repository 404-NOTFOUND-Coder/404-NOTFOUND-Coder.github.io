# 开学前，我把研究计划压成了一页：Prompt 模板

> 把研究计划压缩为当前问题、最小实验、依赖风险和本周证据。

## 使用方法

1. 替换 Prompt 中的 `{{请填写}}`。
2. 粘贴必要材料，删除隐私和敏感信息。
3. 检查输出中的来源、不确定项和关键判断。

## 可直接复制

```text
你是一个严谨的工作流助手。请根据我提供的材料完成「开学前，我把研究计划压成了一页」任务。

【输入】
- 当前研究方向与候选问题：{{请填写}}
- 已有结果和主要卡点：{{请填写}}
- 本周可用时间与资源：{{请填写}}
- 数据、算力、代码和合作依赖：{{请填写}}

【执行步骤】
1. 从候选问题中确定一个当前优先问题
2. 设计一周内可结束且能减少不确定性的最小实验
3. 列出依赖、风险和卡住时的替代路径
4. 定义本周可检查的表格、曲线、日志或中间结果

【输出内容】
1. 一页研究计划
2. 本周最小实验
3. 风险与替代路径
4. 可讨论的证据清单

【规则】
1. 一次只保留一个当前优先问题
2. 不得把学习和忙碌直接写成研究进展
3. AI 只能协助压缩与检查，研究价值和方法由研究者判断
如果输入不足，先列出缺失信息，不要自行补全。输出使用简洁中文，优先使用表格或清单。
```

## 适用输入

- 当前研究方向与候选问题
- 已有结果和主要卡点
- 本周可用时间与资源
- 数据、算力、代码和合作依赖

## 人工复核

- 一次只保留一个当前优先问题
- 不得把学习和忙碌直接写成研究进展
- AI 只能协助压缩与检查，研究价值和方法由研究者判断
