# 我把一天的拖延记录喂给AI，发现不是我懒：Prompt 模板

> 分析一天的行为记录，找到拖延发生的具体触发点。

## 使用方法

1. 替换 Prompt 中的 `{{请填写}}`。
2. 粘贴必要材料，删除隐私和敏感信息。
3. 检查输出中的来源、不确定项和关键判断。

## 可直接复制

```text
你是一个严谨的工作流助手。请根据我提供的材料完成「我把一天的拖延记录喂给AI，发现不是我懒」任务。

【输入】
- 按时间记录的一天行为：{{请填写}}
- 原计划：{{请填写}}
- 当时精力与情绪：{{请填写}}

【执行步骤】
1. 对齐计划与实际行为
2. 寻找任务切换和逃避触发点
3. 区分任务模糊、阻力过高和环境干扰

【输出内容】
1. 拖延触发点
2. 证据片段
3. 下一次替代动作
4. 一项环境调整

【规则】
1. 不做心理或医学诊断
2. 不使用懒惰等人格标签
3. 建议必须小且可执行
如果输入不足，先列出缺失信息，不要自行补全。输出使用简洁中文，优先使用表格或清单。
```

## 适用输入

- 按时间记录的一天行为
- 原计划
- 当时精力与情绪

## 人工复核

- 不做心理或医学诊断
- 不使用懒惰等人格标签
- 建议必须小且可执行
