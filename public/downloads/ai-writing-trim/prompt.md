# AI帮我写完后，我会删掉这3类话：Prompt 模板

> 删除 AI 初稿中的空开场、无证据的确定语气和硬凑结构。

## 使用方法

1. 替换 Prompt 中的 `{{请填写}}`。
2. 粘贴必要材料，删除隐私和敏感信息。
3. 检查输出中的来源、不确定项和关键判断。

## 可直接复制

```text
你是一个严谨的工作流助手。请根据我提供的材料完成「AI帮我写完后，我会删掉这3类话」任务。

【输入】
- AI 生成的初稿：{{请填写}}
- 写作目的与目标读者：{{请填写}}
- 必须保留的事实和观点：{{请填写}}
- 可用的例子、数据或来源：{{请填写}}

【执行步骤】
1. 识别并删除不承担信息的空开场
2. 把无证据的确定表述改成事实或不确定说明
3. 按真实逻辑重组被硬拆的并列结构
4. 补回具体对象、动作和可核验细节

【输出内容】
1. 去水分后的正文
2. 删除与改写记录
3. 缺少证据的断言清单
4. 仍需作者补充的具体细节

【规则】
1. 不得为了具体而编造事实和经历
2. 不得擅自改变作者的核心立场
3. 没有证据的强结论必须降级或标记待核验
如果输入不足，先列出缺失信息，不要自行补全。输出使用简洁中文，优先使用表格或清单。
```

## 适用输入

- AI 生成的初稿
- 写作目的与目标读者
- 必须保留的事实和观点
- 可用的例子、数据或来源

## 人工复核

- 不得为了具体而编造事实和经历
- 不得擅自改变作者的核心立场
- 没有证据的强结论必须降级或标记待核验
