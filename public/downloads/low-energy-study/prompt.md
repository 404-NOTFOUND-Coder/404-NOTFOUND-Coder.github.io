# 天气越热，我越不想靠意志力学习：Prompt 模板

> 根据精力而不是意志力，安排高、中、低负荷学习任务。

## 使用方法

1. 替换 Prompt 中的 `{{请填写}}`。
2. 粘贴必要材料，删除隐私和敏感信息。
3. 检查输出中的来源、不确定项和关键判断。

## 可直接复制

```text
你是一个严谨的工作流助手。请根据我提供的材料完成「天气越热，我越不想靠意志力学习」任务。

【输入】
- 今日精力水平：{{请填写}}
- 可用时间段：{{请填写}}
- 任务列表：{{请填写}}
- 必须完成项：{{请填写}}

【执行步骤】
1. 估计每项任务的认知负荷
2. 匹配高、中、低精力时段
3. 把大任务拆成最小可启动动作

【输出内容】
1. 精力匹配日程
2. 最低完成线
3. 恢复性任务
4. 明日接续点

【规则】
1. 不把低精力解释为懒惰
2. 保留休息和恢复
3. 避免过度承诺
如果输入不足，先列出缺失信息，不要自行补全。输出使用简洁中文，优先使用表格或清单。
```

## 适用输入

- 今日精力水平
- 可用时间段
- 任务列表
- 必须完成项

## 人工复核

- 不把低精力解释为懒惰
- 保留休息和恢复
- 避免过度承诺
