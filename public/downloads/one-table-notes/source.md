# 读完一堆资料后，我只留下这张表

## 备用标题

资料看完就忘？我现在只留这3列

保存一堆资料后，我最后只整理成一张表

## 正文描述

以前我看资料，很容易变成“保存型学习”。

截图、保存、复制金句、存PDF，当下感觉很充实，但过几天再看，还是不知道重点是什么。

后来我改成只留一张表：

原话｜我懂了什么｜怎么用

第一列保留资料原本怎么说，尽量带出处或位置。  
第二列必须用自己的话复述，不复制原文。  
第三列写它能放进哪个问题里，或者能支持什么判断。

如果“怎么用”这一列写不出来，我就先不把它当成有效笔记。

AI可以帮我把材料先摆成表，但不能替我完成理解。真正有用的部分，还是要看我能不能用自己的话讲清楚。

我的判断是：学习笔记的价值，不在于多完整，而在于下次能不能用。
