# 端午祝福别群发｜给导师老板这样写：Prompt 模板

> 根据真实关系与交集，写出没有群发感的节日祝福。

## 使用方法

1. 替换 Prompt 中的 `{{请填写}}`。
2. 粘贴必要材料，删除隐私和敏感信息。
3. 检查输出中的来源、不确定项和关键判断。

## 可直接复制

```text
你是一个严谨的工作流助手。请根据我提供的材料完成「端午祝福别群发｜给导师老板这样写」任务。

【输入】
- 祝福对象及关系：{{请填写}}
- 最近一次真实交集：{{请填写}}
- 平时说话语气：{{请填写}}
- 期望长度：{{请填写}}

【执行步骤】
1. 识别双方关系与合适边界
2. 只使用已提供的真实细节
3. 分别生成克制、自然两个版本

【输出内容】
1. 简短版祝福
2. 自然版祝福
3. 发送前人工修改建议

【规则】
1. 不得编造共同经历
2. 避免空泛节日辞藻
3. 不同对象分别生成
如果输入不足，先列出缺失信息，不要自行补全。输出使用简洁中文，优先使用表格或清单。
```

## 适用输入

- 祝福对象及关系
- 最近一次真实交集
- 平时说话语气
- 期望长度

## 人工复核

- 不得编造共同经历
- 避免空泛节日辞藻
- 不同对象分别生成
