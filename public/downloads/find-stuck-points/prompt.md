# 读不懂资料时，我不让AI总结：Prompt 模板

> 不直接总结难资料，而是先定位术语、逻辑和前置知识卡点。

## 使用方法

1. 替换 Prompt 中的 `{{请填写}}`。
2. 粘贴必要材料，删除隐私和敏感信息。
3. 检查输出中的来源、不确定项和关键判断。

## 可直接复制

```text
你是一个严谨的工作流助手。请根据我提供的材料完成「读不懂资料时，我不让AI总结」任务。

【输入】
- 读不懂的原文段落：{{请填写}}
- 自己的理解：{{请填写}}
- 已掌握的背景知识：{{请填写}}

【执行步骤】
1. 逐句标出术语与指代
2. 还原论证链条
3. 识别缺失的前置知识
4. 给出最短补课路径

【输出内容】
1. 卡点清单
2. 逻辑链
3. 前置知识地图
4. 回读顺序

【规则】
1. 不跳过原文直接给结论
2. 区分原文含义与解释
3. 不确定解释需显式标注
如果输入不足，先列出缺失信息，不要自行补全。输出使用简洁中文，优先使用表格或清单。
```

## 适用输入

- 读不懂的原文段落
- 自己的理解
- 已掌握的背景知识

## 人工复核

- 不跳过原文直接给结论
- 区分原文含义与解释
- 不确定解释需显式标注
