# 节后开工前｜把工作群消息整理成周一待办

## 核心选题

端午假期结束前，把节前散落在工作群里的任务整理成周一行动清单。

## 用户痛点

假期后已经记不清节前答应过什么，任务、负责人和截止时间又散落在不同对话里。

## 内容结构

1. 封面：周一开工前，把工作群变成待办表
2. 痛点：假期前说过什么，回来已经忘了
3. 输入控制：只选和自己有关的消息并脱敏
4. Prompt：提取事项、负责人、时间、出处和追问
5. 对照示例：把模糊消息改成动作与问题
6. 复核：出处、待确认问题、周一优先级和正式录入

## 核心原则

- 摘要不等于可执行的待办。
- 原文没有明确的信息必须标记“待确认”。
- 不需要复制整个工作群，只处理与自己相关的消息。
- AI 负责整理，人负责确认。
- 不上传未经公司允许的敏感工作内容。
