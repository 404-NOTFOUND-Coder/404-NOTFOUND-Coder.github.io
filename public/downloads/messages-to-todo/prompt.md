# 节后开工前｜把工作群消息整理成周一待办：Prompt 模板

> 从零散群消息中提取动作、负责人、时间和追问项。

## 使用方法

1. 替换 Prompt 中的 `{{请填写}}`。
2. 粘贴必要材料，删除隐私和敏感信息。
3. 检查输出中的来源、不确定项和关键判断。

## 可直接复制

```text
你是一个严谨的工作流助手。请根据我提供的材料完成「节后开工前｜把工作群消息整理成周一待办」任务。

【输入】
- 已脱敏且与自己相关的消息：{{请填写}}
- 当前日期：{{请填写}}
- 已有任务清单：{{请填写}}

【执行步骤】
1. 逐条识别明确动作与承诺
2. 提取负责人、截止时间和消息出处
3. 把模糊表述改为待追问问题

【输出内容】
1. 可执行待办表
2. 待确认问题
3. 优先级建议
4. 遗漏风险

【规则】
1. 没有明确的信息标记待确认
2. 不上传敏感工作内容
3. 保留消息出处便于核对
如果输入不足，先列出缺失信息，不要自行补全。输出使用简洁中文，优先使用表格或清单。
```

## 适用输入

- 已脱敏且与自己相关的消息
- 当前日期
- 已有任务清单

## 人工复核

- 没有明确的信息标记待确认
- 不上传敏感工作内容
- 保留消息出处便于核对
