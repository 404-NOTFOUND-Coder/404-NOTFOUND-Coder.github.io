# AI写代码跑偏后，我不再重开对话

## 备用标题

AI写代码跑偏时，我只补这3句话

Coding Agent跑偏后，别急着全部重来

## 正文描述

以前 AI 写代码跑偏，我的第一反应是重新开一个对话，把需求从头再讲一遍。

后来发现，很多时候问题不是上下文太多，而是它在错误方向上继续执行。

现在我会直接做 3 步纠偏：

第一，明确停止当前动作，不再继续改文件。

第二，重新说一次当前唯一目标，删掉不相关要求。

第三，给出一个失败证据，再规定下一步只允许做什么。

比如：先停止改代码。当前目标只是修复导出失败。现有报错是文件路径为空。下一步只定位原因并给出修改方案，不要直接改文件。

这样做的好处是保留了已经读过的项目上下文，又把执行范围重新收紧。

Agent 跑偏时，真正需要的通常不是更长的 Prompt，而是一个清楚的刹车和下一步。

## 图文页脚本

1. AI写代码跑偏后，我不再重开对话
2. 重开对话会丢掉已经建立的项目上下文
3. 第一句：停止当前动作
4. 第二句：重申当前唯一目标
5. 第三句：给失败证据，只允许一个下一步
6. 纠偏的关键不是写更长，而是先刹车
