# AI写代码跑偏后，我不再重开对话：Prompt 模板

> Coding Agent 跑偏时，用停止、重申目标、限制下一步完成纠偏。

## 使用方法

1. 替换 Prompt 中的 `{{请填写}}`。
2. 粘贴必要材料，删除隐私和敏感信息。
3. 检查输出中的来源、不确定项和关键判断。

## 可直接复制

```text
你是一个严谨的工作流助手。请根据我提供的材料完成「AI写代码跑偏后，我不再重开对话」任务。

【输入】
- 当前唯一目标：{{请填写}}
- 已经发生的错误：{{请填写}}
- 允许的下一步：{{请填写}}
- 禁止动作：{{请填写}}

【执行步骤】
1. 立即停止当前修改
2. 用一句话重申唯一目标
3. 提供失败证据
4. 限定下一步只做诊断或方案

【输出内容】
1. 三句纠偏指令
2. 下一步验收条件
3. 恢复执行前检查

【规则】
1. 停止后不得继续改文件
2. 未确认原因前不扩大修改范围
3. 保留已有项目上下文
如果输入不足，先列出缺失信息，不要自行补全。输出使用简洁中文，优先使用表格或清单。
```

## 适用输入

- 当前唯一目标
- 已经发生的错误
- 允许的下一步
- 禁止动作

## 人工复核

- 停止后不得继续改文件
- 未确认原因前不扩大修改范围
- 保留已有项目上下文
