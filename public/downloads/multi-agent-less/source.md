# 同时开3个AI后，我反而更慢了

## 备用标题

多Agent不一定更快，我先看这3个条件

AI能并行干活后，我反而更少同时开

## 正文描述

多 Agent 听起来很诱人：一个找资料，一个写方案，一个检查结果，同时推进。

我实际用下来，发现任务没拆清楚时，同时开得越多，最后合并得越累。

现在只有满足 3 个条件，我才会并行：

第一，任务彼此独立，不需要频繁等待对方结果。

第二，输出格式统一，最后能直接比较或合并。

第三，有一个明确的总负责人，负责检查冲突和做最终决定。

如果这三个条件不满足，我宁愿让一个 Agent 按顺序做完。

并行不是把同一个问题复制三份，而是把能独立验收的工作拆开。

Agent 越多，越需要清楚的边界、格式和验收标准。
