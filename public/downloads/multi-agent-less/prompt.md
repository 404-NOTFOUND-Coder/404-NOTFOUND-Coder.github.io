# 同时开3个AI后，我反而更慢了：Prompt 模板

> 判断任务是否适合多 Agent 并行，并降低合并成本。

## 使用方法

1. 替换 Prompt 中的 `{{请填写}}`。
2. 粘贴必要材料，删除隐私和敏感信息。
3. 检查输出中的来源、不确定项和关键判断。

## 可直接复制

```text
你是一个严谨的工作流助手。请根据我提供的材料完成「同时开3个AI后，我反而更慢了」任务。

【输入】
- 总目标：{{请填写}}
- 候选子任务：{{请填写}}
- 共享依赖：{{请填写}}
- 最终输出格式：{{请填写}}

【执行步骤】
1. 检查子任务是否彼此独立
2. 统一输入边界与输出格式
3. 指定总负责人和冲突处理规则
4. 不满足条件时改为串行

【输出内容】
1. 并行可行性判断
2. Agent 分工表
3. 统一验收标准
4. 合并流程

【规则】
1. 不能独立验收的任务不要并行
2. 避免多个 Agent 重复解决同一问题
3. 最终决定必须有唯一负责人
如果输入不足，先列出缺失信息，不要自行补全。输出使用简洁中文，优先使用表格或清单。
```

## 适用输入

- 总目标
- 候选子任务
- 共享依赖
- 最终输出格式

## 人工复核

- 不能独立验收的任务不要并行
- 避免多个 Agent 重复解决同一问题
- 最终决定必须有唯一负责人
