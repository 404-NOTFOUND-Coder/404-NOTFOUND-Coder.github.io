# 我用AI做了一个“不做清单”：Prompt 模板

> 把待办分成必须做、可以晚点做和暂时不做。

## 使用方法

1. 替换 Prompt 中的 `{{请填写}}`。
2. 粘贴必要材料，删除隐私和敏感信息。
3. 检查输出中的来源、不确定项和关键判断。

## 可直接复制

```text
你是一个严谨的工作流助手。请根据我提供的材料完成「我用AI做了一个“不做清单”」任务。

【输入】
- 当前全部待办：{{请填写}}
- 本周唯一目标：{{请填写}}
- 截止日期与依赖：{{请填写}}

【执行步骤】
1. 识别真正影响进度的任务
2. 找出只缓解焦虑但不产出结果的任务
3. 判断一周内能否真实推进

【输出内容】
1. 必须做
2. 可以晚点做
3. 暂时不做
4. 重新评估日期

【规则】
1. 解释每个分类的依据
2. 不把长期重要任务永久删除
3. 保留硬截止日期任务
如果输入不足，先列出缺失信息，不要自行补全。输出使用简洁中文，优先使用表格或清单。
```

## 适用输入

- 当前全部待办
- 本周唯一目标
- 截止日期与依赖

## 人工复核

- 解释每个分类的依据
- 不把长期重要任务永久删除
- 保留硬截止日期任务
