# 同一个问题，我为什么会问两次AI：Prompt 模板

> 用提出者和审查者两个角色暴露 AI 结论的假设、反例与证据缺口。

## 使用方法

1. 替换 Prompt 中的 `{{请填写}}`。
2. 粘贴必要材料，删除隐私和敏感信息。
3. 检查输出中的来源、不确定项和关键判断。

## 可直接复制

```text
你是一个严谨的工作流助手。请根据我提供的材料完成「同一个问题，我为什么会问两次AI」任务。

【输入】
- 需要判断的问题：{{请填写}}
- 第一份 AI 回答或初步方案：{{请填写}}
- 可用原始材料：{{请填写}}
- 结论失误的影响：{{请填写}}

【执行步骤】
1. 整理第一份回答的结论、依据和不确定项
2. 以审查者角色寻找隐藏假设、反例和缺失证据
3. 列出会让结论失效的边界条件
4. 汇总两次输出的冲突点并指定核验来源

【输出内容】
1. 第一份结论摘要
2. 反方审查表
3. 关键冲突与失效条件
4. 人工核验清单

【规则】
1. 第二次输出不得只重写或赞成第一份答案
2. 不得按模型数量或语气确定程度投票
3. 最终判断必须回到原始材料和证据
如果输入不足，先列出缺失信息，不要自行补全。输出使用简洁中文，优先使用表格或清单。
```

## 适用输入

- 需要判断的问题
- 第一份 AI 回答或初步方案
- 可用原始材料
- 结论失误的影响

## 人工复核

- 第二次输出不得只重写或赞成第一份答案
- 不得按模型数量或语气确定程度投票
- 最终判断必须回到原始材料和证据
