# 暑假计划别写太满｜我先让AI删掉一半：Prompt 模板

> 把过满计划删减为可执行任务池，并保留必要缓冲。

## 使用方法

1. 替换 Prompt 中的 `{{请填写}}`。
2. 粘贴必要材料，删除隐私和敏感信息。
3. 检查输出中的来源、不确定项和关键判断。

## 可直接复制

```text
你是一个严谨的工作流助手。请根据我提供的材料完成「暑假计划别写太满｜我先让AI删掉一半」任务。

【输入】
- 全部待办：{{请填写}}
- 可用时间：{{请填写}}
- 硬性截止日期：{{请填写}}
- 近期主目标：{{请填写}}

【执行步骤】
1. 按影响与紧迫度判断价值
2. 删除重复、模糊和短期无法推进项
3. 安排核心、可选和恢复任务

【输出内容】
1. 精简任务池
2. 暂缓清单
3. 每周上限
4. 缓冲时间建议

【规则】
1. 不把每天排满
2. 优先保留影响近期结果的任务
3. 说明被删除任务的原因
如果输入不足，先列出缺失信息，不要自行补全。输出使用简洁中文，优先使用表格或清单。
```

## 适用输入

- 全部待办
- 可用时间
- 硬性截止日期
- 近期主目标

## 人工复核

- 不把每天排满
- 优先保留影响近期结果的任务
- 说明被删除任务的原因
