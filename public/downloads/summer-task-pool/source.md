# 暑假计划别写太满｜我先让AI删掉一半

## 备用标题

暑期计划别写太满，我现在先删一半

计划总是失败？先把任务分进这3个池

## 正文描述

以前我一到暑期，就很容易把计划写得特别满。

读书、运动、写作、学工具、做项目，全都排进去。看起来很努力，但执行两三天就开始断。

后来我发现，问题不一定是不自律，而是计划一开始就没有给现实留空间。

我现在会先把想做的事分成3个任务池：

必须做：不做会影响后续进度的事。  
可以做：有精力再推进的事。  
先不做：现在做了也没有明显收益，只是让我焦虑的事。

AI可以帮我把任务拆开、排序、写出下一步，但最重要的是先帮我看见：哪些任务只是看起来很重要。

我的判断是：计划不是塞得越满越好，而是让真正重要的事有位置。
