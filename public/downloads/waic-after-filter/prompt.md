# AI大会看完，我只留下3个能用的方向：Prompt 模板

> 把大会热点归入整理、复核和流程三类可用方向。

## 使用方法

1. 替换 Prompt 中的 `{{请填写}}`。
2. 粘贴必要材料，删除隐私和敏感信息。
3. 检查输出中的来源、不确定项和关键判断。

## 可直接复制

```text
你是一个严谨的工作流助手。请根据我提供的材料完成「AI大会看完，我只留下3个能用的方向」任务。

【输入】
- 会后笔记或产品清单：{{请填写}}
- 自己的高频任务：{{请填写}}
- 验证所需成本：{{请填写}}

【执行步骤】
1. 逐项映射到整理、复核或固定流程
2. 设计一个最小验证任务
3. 比较迁移成本和实际收益

【输出内容】
1. 可用方向清单
2. 最小实验
3. 观察指标
4. 暂不采用项

【规则】
1. 不把演示效果当稳定能力
2. 一次只验证一个变量
3. 没有任务匹配时不强行采用
如果输入不足，先列出缺失信息，不要自行补全。输出使用简洁中文，优先使用表格或清单。
```

## 适用输入

- 会后笔记或产品清单
- 自己的高频任务
- 验证所需成本

## 人工复核

- 不把演示效果当稳定能力
- 一次只验证一个变量
- 没有任务匹配时不强行采用
