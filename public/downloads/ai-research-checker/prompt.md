# AI做研究越强，我越常让它挑错：Prompt 模板

> 让 AI 在问题、证据和结果三个阶段主动挑错。

## 使用方法

1. 替换 Prompt 中的 `{{请填写}}`。
2. 粘贴必要材料，删除隐私和敏感信息。
3. 检查输出中的来源、不确定项和关键判断。

## 可直接复制

```text
你是一个严谨的工作流助手。请根据我提供的材料完成「AI做研究越强，我越常让它挑错」任务。

【输入】
- 研究问题或草稿：{{请填写}}
- 已有证据：{{请填写}}
- 当前结论：{{请填写}}
- 适用范围：{{请填写}}

【执行步骤】
1. 寻找隐藏假设和不可验证说法
2. 分开支持、反对与缺失证据
3. 寻找矛盾、边界条件和替代解释

【输出内容】
1. 问题阶段检查
2. 证据矩阵
3. 结果反例
4. 优先修正项

【规则】
1. 没找到不等于不存在
2. 不得替研究者决定问题价值
3. 最终结论由人负责
如果输入不足，先列出缺失信息，不要自行补全。输出使用简洁中文，优先使用表格或清单。
```

## 适用输入

- 研究问题或草稿
- 已有证据
- 当前结论
- 适用范围

## 人工复核

- 没找到不等于不存在
- 不得替研究者决定问题价值
- 最终结论由人负责
