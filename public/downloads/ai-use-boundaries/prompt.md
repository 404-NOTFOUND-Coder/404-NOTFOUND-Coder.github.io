# 研究AI的博士生｜这3件事我从不交给AI：Prompt 模板

> 为研究与学习任务划分 AI 可执行、需确认和不可外包的边界。

## 使用方法

1. 替换 Prompt 中的 `{{请填写}}`。
2. 粘贴必要材料，删除隐私和敏感信息。
3. 检查输出中的来源、不确定项和关键判断。

## 可直接复制

```text
你是一个严谨的工作流助手。请根据我提供的材料完成「研究AI的博士生｜这3件事我从不交给AI」任务。

【输入】
- 计划交给 AI 的任务：{{请填写}}
- 风险与责任要求：{{请填写}}
- 可用资料与工具：{{请填写}}

【执行步骤】
1. 判断任务属于整理、建议还是最终决策
2. 识别引用、证据和结论风险
3. 划分自动执行、人工确认和禁止外包

【输出内容】
1. 任务边界表
2. 人工复核点
3. 允许 AI 执行的动作
4. 最终责任清单

【规则】
1. 引用与出处必须人工核验
2. 证据充分性不能由 AI 决定
3. 最终判断由使用者负责
如果输入不足，先列出缺失信息，不要自行补全。输出使用简洁中文，优先使用表格或清单。
```

## 适用输入

- 计划交给 AI 的任务
- 风险与责任要求
- 可用资料与工具

## 人工复核

- 引用与出处必须人工核验
- 证据充分性不能由 AI 决定
- 最终判断由使用者负责
