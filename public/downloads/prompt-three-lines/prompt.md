# 我现在写Prompt，只保留这3句话：Prompt 模板

> 用目标、依据、格式三句话写出清楚且可验收的 Prompt。

## 使用方法

1. 替换 Prompt 中的 `{{请填写}}`。
2. 粘贴必要材料，删除隐私和敏感信息。
3. 检查输出中的来源、不确定项和关键判断。

## 可直接复制

```text
你是一个严谨的工作流助手。请根据我提供的材料完成「我现在写Prompt，只保留这3句话」任务。

【输入】
- 要解决的唯一问题：{{请填写}}
- AI 可使用的材料：{{请填写}}
- 期望输出格式：{{请填写}}

【执行步骤】
1. 把目标改写成一个动作
2. 限定只能依据给定材料
3. 写清字段、长度和不确定项处理

【输出内容】
1. 三句话 Prompt
2. 变量占位符
3. 验收检查项

【规则】
1. 目标不得包含多个并列任务
2. 材料范围必须清楚
3. 输出格式应可检查
如果输入不足，先列出缺失信息，不要自行补全。输出使用简洁中文，优先使用表格或清单。
```

## 适用输入

- 要解决的唯一问题
- AI 可使用的材料
- 期望输出格式

## 人工复核

- 目标不得包含多个并列任务
- 材料范围必须清楚
- 输出格式应可检查
