# AI真看懂视频了吗？我只测3件事：Prompt 模板

> 用时间顺序、状态变化和证据时间点测试视频理解能力。

## 使用方法

1. 替换 Prompt 中的 `{{请填写}}`。
2. 粘贴必要材料，删除隐私和敏感信息。
3. 检查输出中的来源、不确定项和关键判断。

## 可直接复制

```text
你是一个严谨的工作流助手。请根据我提供的材料完成「AI真看懂视频了吗？我只测3件事」任务。

【输入】
- 视频或带时间戳转写：{{请填写}}
- 希望验证的结论：{{请填写}}
- 关键事件列表：{{请填写}}

【执行步骤】
1. 复述关键事件的时间顺序
2. 标出对象状态变化
3. 为每个结论定位证据时间点
4. 列出不确定项

【输出内容】
1. 时间轴
2. 状态变化表
3. 结论证据索引
4. 失败样例

【规则】
1. 摘要不能代替证据定位
2. 看不到的内容不得猜测
3. 最终判断回到原视频
如果输入不足，先列出缺失信息，不要自行补全。输出使用简洁中文，优先使用表格或清单。
```

## 适用输入

- 视频或带时间戳转写
- 希望验证的结论
- 关键事件列表

## 人工复核

- 摘要不能代替证据定位
- 看不到的内容不得猜测
- 最终判断回到原视频
