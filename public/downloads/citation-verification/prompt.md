# AI给的引用，我只信能点开的：Prompt 模板

> 逐条核验 AI 引用是否真实存在、准确对应并支持当前结论。

## 使用方法

1. 替换 Prompt 中的 `{{请填写}}`。
2. 粘贴必要材料，删除隐私和敏感信息。
3. 检查输出中的来源、不确定项和关键判断。

## 可直接复制

```text
你是一个严谨的工作流助手。请根据我提供的材料完成「AI给的引用，我只信能点开的」任务。

【输入】
- 待核验的结论与引用：{{请填写}}
- AI 给出的链接或书目信息：{{请填写}}
- 原始任务或研究主题：{{请填写}}
- 需要使用的引用格式：{{请填写}}

【执行步骤】
1. 检查链接可访问性并核对题目、作者、年份
2. 定位原文证据并判断是否支持当前结论
3. 优先追溯论文、官方报告或一手数据
4. 按可用、部分支持、冲突、未核验分类

【输出内容】
1. 引用核验表
2. 可安全使用的引用
3. 应删除或改写的结论
4. 仍需人工查找的来源

【规则】
1. 不得生成或补全不存在的引用
2. 关键词相关不等于原文支持结论
3. 无法打开或无法定位原文时必须标记未核验
如果输入不足，先列出缺失信息，不要自行补全。输出使用简洁中文，优先使用表格或清单。
```

## 适用输入

- 待核验的结论与引用
- AI 给出的链接或书目信息
- 原始任务或研究主题
- 需要使用的引用格式

## 人工复核

- 不得生成或补全不存在的引用
- 关键词相关不等于原文支持结论
- 无法打开或无法定位原文时必须标记未核验
